How to use this list

Every prompt below has a placeholder like [TOPIC]. Replace it with your subject before you send it to the AI. One prompt per Reel is enough — hook first, then script, then caption.

1

Pick a prompt

Start with the hook category. A Reel lives or dies in the first 3 seconds.

2

Replace [TOPIC]

Be specific. "Selling digital products in India" beats "business".

3

Ask for Hinglish

Add "in Hinglish" to the prompt if the first answer sounds like a textbook.

4

Edit before filming

Keep 20% of the AI output. Rewrite the rest in your own words.

1. Reel hooks — pehle 3 second

Hook decides whether anyone watches. These prompts give you 10 openers you can test.

  • Write 10 Instagram Reel hooks (under 8 words each) for a video about [TOPIC]. Use curiosity, a number, or a bold claim. Hinglish.

2. Reel scripts — 30 second

A 30-second Reel needs 4 beats: hook, problem, value, CTA. Ask for that shape.

  • Write a 30-second Reel script about [TOPIC] with 4 beats: hook (3s), problem (7s), value (15s), CTA (5s). Hinglish.
  • Turn this idea into a 30-second Reel script: [IDEA]. Add on-screen text for each beat.
  • Write a 45-second talking-head Reel script about [TOPIC] with a story opener.
  • Create a 30-second Reel script that debunks a myth about [TOPIC].
  • Write a 30-second 'day in the life' Reel script for an Indian [PROFESSION].
  • Turn this blog post into a 30-second Reel script: [PASTE TEXT].
  • Write a 30-second Reel script with a list format (5 points) about [TOPIC].
  • Create a 30-second Reel script where the first line contradicts the last line (loop bait).
  • Write a 20-second Reel script for a product demo of [PRODUCT].
  • Write a 60-second Reel script about [TOPIC] with a strong emotional close.

FAQ

Do AI prompts actually work for Instagram Reels?

They work as a starting draft. AI gives you structure and options; you still have to add your own story, your own examples and your own voice. A raw AI script sounds generic — edit it before filming.

Which AI tool should I use?

Any of ChatGPT, Gemini, Claude or Perplexity will handle these prompts. Paste the prompt, replace the [TOPIC] placeholder with your subject, and ask for a second version in Hinglish if the first one sounds too formal.

How many prompts do I need per Reel?

One prompt per Reel is enough if you run it well: hook prompt, then script prompt, then caption prompt. Three prompts per Reel is the working rhythm for most creators.

Can I use these prompts for YouTube Shorts?

Yes. Shorts and Reels share the same hook-problem-value-CTA structure. Only the safe-area and the length advice change slightly.
